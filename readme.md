# 🎨 Image Generator Web App

🔗 **Live Demo:** https://celadon-dodol-7a69fe.netlify.app/

An interactive **AI Image Generator Web App** that converts text prompts into stunning images using powerful AI models. Designed with a clean UI and smooth user experience.

---

## 🚀 Features

* 🖼️ Generate images from text prompts
* 🤖 Multiple model selection
* ⚡ Fast API-based generation
* 🎯 Choose number of images
* 🌙 Light/Dark mode toggle
* 📱 Fully responsive design
* ⬇️Download created images

---

## 🛠️ Tech Stack

### Frontend

* HTML
* CSS (Flexbox & Grid)
* JavaScript

### Backend

* Node.js
* Express.js

### API

* Hugging Face Inference API

---

## ⚙️ How It Works

1. Enter a **text prompt**
2. Select your preferred **AI model**
3. Choose number of images
4. Click generate 🚀
5. Images appear instantly on screen

---

## 📸 Example Prompt

```
A magical forest with glowing trees and fireflies, ultra realistic
```

## ❗ Common Issues

* ❌ Invalid API key
  → Check your `.env` file

* ❌ Images not loading
  → Verify API response in console

* ❌ Backend error (500)
  → Check server logs
